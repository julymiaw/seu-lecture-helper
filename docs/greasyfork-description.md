# SEU 研究生讲座预约助手

适用于东南大学研究生“人文与科学素养系列讲座”预约系统。在活动列表和详情页原按钮旁增加“预约助手”，通过独立弹窗完成定时预约、余位监测、验证码识别和预约结果核验。

安装后直接在浏览器中使用，无需本地服务、额外软件或 API 密钥。

[项目源码](https://github.com/julymiaw/seu-lecture-helper) · [问题反馈](https://github.com/julymiaw/seu-lecture-helper/issues) · [完整使用说明](https://github.com/julymiaw/seu-lecture-helper#readme)

## 主要功能

- **定时预约**：提前选择活动并启动倒计时，到开放时间自动获取验证码，识别后提交。
- **余位监测**：满员活动可开启低频监测，发现余位后自动获取验证码、识别并尝试预约。
- **本地验证码识别**：图片在浏览器中处理，无需上传至第三方识别服务。识别异常或验证码错误时自动换图重试，立即查询当前余位，仍有名额就换图重试；成功、满员或预约结束时停止，不设固定次数上限和额外等待。
- **结果核验**：提交后查询个人预约记录，确认成功后将助手按钮更新为“已预约”；提交超时也会先核验，不直接重复提交。
- **收起与恢复**：收起弹窗后继续等待或监测，点击活动旁的助手按钮即可恢复同一任务。

## 使用方法

在本页面安装脚本，或通过 [GitHub 安装链接](https://raw.githubusercontent.com/julymiaw/seu-lecture-helper/main/dist/seu-lecture-helper.user.js)安装。两处提供的是同一个脚本，保留一份启用即可。

安装脚本后，登录[东南大学研究生讲座预约系统](https://ehall.seu.edu.cn/gsapp/sys/yddjzxxtjappseu/*default/index.do#/hdyy)，刷新页面，点击活动旁的“预约助手”。

### 定时预约

1. 选择“定时预约”和验证码方式：自动识别或手动输入。
2. 点击“开始等待”；已开放的活动显示“立即预约”。
3. 倒计时结束后自动获取验证码。自动模式识别后提交；手动模式输入验证码，按回车或点击“提交预约”。
4. 提交后自动核验预约记录。

可勾选“未抢到时继续监测余位”，在提交明确返回满员时转入余位监测。未勾选时，会提供“开始监测”按钮，由你决定是否继续。

### 余位监测

人数已满时默认选中“余位监测”，点击“开始监测”后才启动。打开弹窗本身不会开始监测或提交预约。

- 检查间隔可选 **30、60、120 秒**，默认 60 秒，实际间隔有约 ±10% 的随机偏移。
- 修改间隔保留本轮倒计时，下一轮使用新设置。
- “立即检查”位于“停止监测”左侧，点击后立即检查一次，完成后按当前间隔重新计时。请求进行中按钮禁用，不并发查询。
- 满员时只查询人数，不反复获取验证码；出现余位后暂停人数查询，进入预约流程。
- 监测默认使用自动识别，正常情况下禁用手动输入；识别或验证码错误先立即查询余位，仍有名额就换图重试，无次数上限和固定等待；模型资源不可用时开放手动输入。
- 支持暂停、继续和收起；点击“停止监测”结束任务。

## 验证码资源与缓存

首次使用自动识别需要下载约 **27 MB** 的模型、字符表和识别引擎，请提前打开弹窗准备资源。资源从 jsDelivr 下载，失败时尝试 UNPKG，并校验文件完整性。

下载完成后缓存在浏览器中，后续复用，无需每次重新下载。清理学校站点数据或浏览器清除缓存后，可能需要重新下载。资源无法加载时会转为手动输入。

脚本使用学校页面已有的登录状态，不保存密码、Cookie 或验证码。向资源下载站点发送的请求不携带学校 Cookie 或验证码；识别过程在本地完成。

## 使用须知

- 适配的是上述**研究生预约入口**，不保证兼容本科生或其他预约系统。
- 请使用新版 Chrome／Edge 和 Tampermonkey 等用户脚本管理器；其他浏览器尚未验证。
- 等待或监测期间需保持页面打开、登录有效。收起弹窗会继续运行；刷新、关闭页面或离开预约页面会结束当前任务。
- 后台标签页节流、电脑休眠和网络拥堵可能延迟执行。脚本不保证识别正确或预约成功，获取验证码也不代表占位。
- 同一浏览器、同一站点只允许一个助手预约任务。已预约、已取消或预约结束的活动不会自动提交，脚本不会取消已有预约。
- 登录异常或限流时停止继续请求；网络故障时退避重试，连续失败后暂停。“立即检查”不能跳过未开放时间或故障退避。
- 成功后助手按钮显示“已预约”；学校原按钮可能仍显示旧状态，可点击结果面板中的“刷新学校页面”更新。

这是非官方辅助工具，请遵守学校预约和参与活动的要求。
