# 当前测试计划

自动测试仅使用本地接口样例，浏览器测试的模型、WASM 与学校请求均从本地返回。

1. T-30s 取图、T 和 T+49ms 不提交、T+50ms 单次提交；OCR 迟到后立即提交，重试和候选切换不叠加固定等待。服务器时间字段缺省／偏差不影响解析或调度。
2. OCR 初始化失败的使用时重试、数字不完整／识别失败／验证码拒绝／未开放立即换图；取图网络失败有限重试。资源缓存、完整性校验和无凭据下载。
3. 仅明确满员切换下一候选；双满终止；登录暂停、限流停止、已预约转核验；提交结果不明先核验、不重发。
4. 单／双候选统一状态、桌面／窄屏、收起不终止、无人工验证码或场次标注、候选按钮同步。
5. 站内详情及前进／后退保留等待；模拟页面缓存 pagehide/pageshow 恢复；明确关闭清意图、释放锁。整页缓存的真实站点触发条件不在离线保证内。
6. 同页登录恢复、刷新恢复、候选和核验屏障、过截止仍可核验；旧回包不改变关闭／新任务；存储 getter、读写失败不打断执行。
7. JSON 日志跨刷新关联、限量保留与截断、跨页面写入合并、异常时内存导出。阶段只记录结果耗时，保留提交开始及安全错误反馈；无服务器偏移、图片、答案和登录凭据。

实网证据：2026-10-20 的 0.7.8 线上首次提交成功并核验，图片持有约 29.4 秒。1.0 的清理改动只做离线回归，不能等同于新版本再次实网成功，也不证明验证码最长有效期。
