# 必要测试与验收

开发测试运行期间禁止真实域名联网，OCR CDN 地址也由本地固定资源响应；准备阶段可下载公开模型和 WASM 并校验，不能访问学校。注入 fetch、时间与计时器。使用购票福利作为活动语义样例，不将它的历史开放时间直接用于实时时钟测试。测试失败时不得降级到学校接口。

## 请求与数据

- POST 表单编码、验证码 GET 参数、正确接口前缀与同源登录态。
- 列表人数和预约状态按 ID 合并，数字／字符串兼容。
- 不同线上／线下、同名不同 ID、列表重排不选错活动。
- 我的活动按 `HD_WID` 与非空预约 ID 核验；其他活动、空记录、活动取消不误报成功。
- HTTP 200 业务失败、非 JSON、401/403、重定向 HTML、429、网络中断、超时区分。后几项是模拟异常，不代表已观察到学校实际格式。

## 任务与时间

- 上海时区解析、服务器偏移、未开放／刚到点／已开放／已结束。
- 到点精确触发一次；计时器晚唤醒仍按绝对时间执行，不补发多轮。
- 已预约不取验证码；关闭前的延迟响应不重开弹窗；切换任务丢弃旧结果。
- 有限取图重试；业务错误不循环；刷新验证码与提交互斥。
- 成功响应后核验、超时但已成功、延迟可见、核验失败及最终未知状态。
- 提交最多一次，未知状态仅查询；手动核验不自动预约。
- 单实例互斥、跨标签页冲突及过期锁恢复。

## DOM 与交互

- 实际列表最小 DOM 上按钮位置、重复挂载、重排、SPA 路由切换、隐藏缓存页。
- Vue 只读 ID 适配用模拟对象；缺失时唯一匹配／歧义停止。
- 详情页从 hash 取 ID，使用模板重建的 footer 样例。
- 点新增按钮不触发卡片导航，不改变原按钮。
- 验证码完整 data URI 渲染与焦点；按钮／回车共用提交锁；空输入、输入法回车。
- 关闭弹窗取消等待；提交中的关闭不能显示“已取消预约”。
- 窄屏、长标题、状态文本、键盘操作的本地浏览器冒烟测试。

## OCR 与模式

- 倒计时预热不提前取验证码；到点取图、真实模型推理、一次自动提交并核验。
- 切换手动、换图和关闭时丢弃迟到识别，手动模式不加载模型。
- 验证资源字节数／SHA-256、坏缓存清除、一次备用源、禁止携带 Cookie／Referer；新页面复用缓存。
- 加载失败或不完整结果保留原图并聚焦手动输入；验证码拒绝不循环自动提交。
- 原生模式选择键盘操作，提交中锁定；375 px 弹窗截图，学校按钮同高同宽样例断言。
- 准备阶段使用固定公开文件，完整分发文件浏览器测试拒绝任何未匹配的外部请求和动态远程 JS。

## 样例与来源

见 `tests/fixtures/manifest.json`。observed 表示原成功／失败业务响应；derived 表示从实际前端状态裁剪或重新组合，非原始 HTTP body；synthetic 表示人工构造。

购票福利 observed 当前已预约；测试“未预约、到点、验证码错误、网络超时”等应显式生成 synthetic 变体，不伪造实测来源。测试验证码用独立 SVG 占位图，不保存真实挑战。

## 能验收与不能验收

现有资料足够开发核心请求、挂载与交互并完成离线测试。无需为了这些测试继续请求真实系统。

离线测试不能证明：成品在 Tampermonkey 的隔离环境、学校后续改版、高峰服务端响应、验证码时效和跨设备行为。当前没有“新脚本省略 appiontCheck 后真实提交成功”的记录。上线说明应列明这些限制，不能将离线全绿写成实网验收通过；将来若要实网验收，再确定测试范围。
