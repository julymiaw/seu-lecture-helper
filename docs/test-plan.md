# 当前测试计划

所有自动测试使用本地接口样例，不访问学校。真实 OCR 浏览器测试将固定模型与 WASM 从本地缓存返回。

1. 固定提前 30 秒、旧配置恢复兼容、服务器时间偏差、开放前不提交、到点只提交一次。
2. 验证码与数字不显示在界面；无验证码输入、提交或换图入口；迟到 OCR 不恢复旧任务，准备完成不自动展开收起的面板。
3. OCR 跨过开放时间才完成时立即提交；取图、准备或识别跨截止则停止、不提交；识别失败或数字不完整立即换图，包括开放前。
4. 明确验证码拒绝或未开放可换图重试；满员按顺序切换，双满停止。登录暂停、限流停止，已预约转核验。无余位监测。
5. 模型预热失败后使用时再初始化，覆盖预热与启动重叠，持续失败停止且无人工回退；资源缓存、完整性校验和无凭据下载。
6. 提交期间锁定关闭及重复提交；写入超时先核验，核验有限重试后保留未知状态。
7. 连续登录失败保留完整候选；预约结束后仍恢复待核验记录，直接核验、不查活动或提交；元数据临时失败保留意图，核验成功更新主按钮。
8. 列表与详情挂载、路由切换、跨标签页任务互斥、关闭时废弃旧响应。
9. 桌面和窄屏布局；收起后任务保留，后台准备不展开面板，仅终态显示结果。单／双候选统一行内进度，识别失败维持单目标、无人工标注，停止原因和预热警告不重复显示。
10. 日志跨刷新关联、十任务和十四天清理、事件截断、跨页面写入合并、慢写入与存储失败内存导出；导出不含验证码图或答案及登录凭据。

真实验收另行验证提前验证码有效期和 19:00 高峰延迟；离线测试不证明这两项。

校时回归：周期与最终详情检查、校时修正同时移动取图和提交、超过 2 秒样本不覆盖、失败沿用旧基准、详情在途不阻塞取图、迟到详情不得影响关闭／新任务。执行器和界面均按本机时间加服务器偏移判断开放。
