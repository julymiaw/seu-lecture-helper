# 0.4.0 测试计划

所有自动测试使用本地接口样例，不访问学校。真实 OCR 浏览器测试将固定模型与 WASM 从本地缓存返回。

1. 提前时间配置、服务器时间偏差、开放前不提交、到点只提交一次。
2. 图片和答案同时显示；人工修改不被迟到 OCR 覆盖；换图清空旧答案并废弃旧结果。
3. OCR 跨过开放时间才完成时立即提交；开放前识别失败不刷图，开放后按余位换图重试。
4. 明确验证码拒绝可重试；满员、人数未知、结束、登录或限流停止。无监测定时器。
5. 模型资源失败保留人工输入；缓存、完整性校验和资源请求不携带学校凭据。
6. 提交期间锁定输入、关闭及重复提交；写入超时先核验，核验有限重试后保留未知状态。
7. 列表与详情挂载、路由切换、跨标签页任务互斥、关闭时废弃旧响应。
8. 桌面和窄屏视觉检查；收起后任务保留，验证码到达时恢复。

真实验收另行验证提前验证码有效期和 19:00 高峰延迟；离线测试不证明这两项。
