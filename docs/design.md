# 第一版设计（v0.1.0 历史记录）

v0.2.0 已增加浏览器本地 OCR、验证码模式选择和按钮尺寸适配；新增设计见 [OCR 与弹窗](ocr.md)。下文保留第一版实现依据，人工输入限定不适用于 v0.2.0 的自动模式。

## 范围与流程

独立油猴脚本，源码分模块、构建单文件；浏览器原有登录态；验证码人工输入。学校 DOM 只用于挂载按钮，不点击原按钮、不调用学校 Vue 方法。

```text
点击新增按钮 → 检查已有预约／时间窗口 → 等待开放（如需）
→ 获取验证码 → 聚焦输入 → 用户提交 → 查询核验 → 成功／失败／结果待确认
```

不调用 `appiontCheck`（详情页源码同样省略）；不实现取消、OCR、循环捡漏、自动登录或固定保活。关闭弹窗取消未提交任务及定时器；提交和核验期间暂时禁用关闭（含 Esc），完成后允许关闭；结果不明保留手动核验入口。关闭页面不能撤销已发出的预约。重开或切换活动使旧异步结果不能覆盖新弹窗。

## 最小模块

| 模块 | 输入与输出／责任 |
|---|---|
| `api.ts` | 同源请求、表单编码、响应解析、活动合并与预约核验；可注入 fetch 作离线测试 |
| `reservation.ts` | 目标活动、计时、单任务、取图、提交和核验状态；可注入时间／计时器 |
| `dialog.ts` | 只渲染状态，发出提交、换图、关闭事件；文本用 textContent，隔离样式 |
| `mount.ts` | 列表和详情页适配、路由及 DOM 重绘、避免重复挂载；只读学校数据 |
| `main.ts` | 初始化与连接模块 |

无需通用插件体系、多层 service/repository 抽象或复杂配置系统。

## 挂载证据

列表每张卡片为 `.activity-container`，标题在 `.activity-name [title]`，动作区为 `.activity-content .ydd-inline-flex.ydd-pull-right.ydd-pt-14`。卡片点击会进入详情，因此新增按钮须阻止事件冒泡，不改变原按钮监听器。

实际卡片没有 WID 属性或详情链接。已只读验证其 `__vue__` 的 `$parent` 链存在 `common-activity`，`$props.item.WID` 是目标 ID。开发优先使用这条小范围只读适配获取准确 ID，再与接口活动按 ID 关联；不读取整个应用状态，不调用 Vue 方法。

如果用户脚本隔离环境无法访问组件属性，可用完整标题、活动时间和地点与接口作唯一匹配，重名／歧义时不给错误目标绑定按钮。不得按行号匹配，也不偷偷打开详情获取 ID。产物使用 `@grant none`，不依赖 `unsafeWindow`；实际管理器部署尚未验收。

详情路由 `#/hdxq?WID=...`，ID 直接解析 hash 的查询参数；挂载到 `.hdxq-foot` 原按钮旁。详情模板已取得，但本轮未新增详情页渲染快照；详情 HTML 测试样例是依据模板重建的最小结构，不冒充实测 DOM。

监听 hash 变化及局部 DOM 变更；重绘后确保同一卡片仅一个按钮。通知／我的活动不误挂；路由离开时清理观察器与未提交等待。SPA 缓存页面可能仍留在 DOM，不能给隐藏页重复挂载。

## 交互与请求预算

- 点击时取必要活动数据并校准时间；已预约只显示状态，不取图、不自动取消。
- 倒计时采用目标绝对时间；到点只触发一次。标签页后台延迟无法完全消除。
- 输入框显示后聚焦；验证码只约定最长 4 字符，不从单张样例推导必须纯数字。
- 按钮与回车共享提交锁；避免输入法 composing 回车误提交。
- 刷新验证码期间禁用提交，旧图／旧响应不覆盖新挑战。
- 取图网络故障最多再尝试 2 次，间隔 1、2 秒；关闭或明确业务失败时停止。参数是产品选择，不是服务端允许的配额。
- 提交成功或网络结果不明后核验：立即查询，必要时 1、2 秒后各查询一次，仍不明确则停留“结果待确认”，提供手动核验。最多 3 次，不自动重复提交。
- 同一运行实例只允许一个活动任务；跨标签页用 Web Locks 原子互斥，崩溃或关闭标签页会由浏览器释放锁；不使用持久化锁。不宣称能约束其他设备或学校原按钮。
- 显示服务端业务提示、登录失效／非 JSON、网络故障的区别，不解析不存在的固定登录错误码。

## 发布

已使用 TypeScript、esbuild、Vitest/jsdom 和 Playwright；接口层约 100 行，状态管理独立。产物包含代码、样式、油猴元信息；不远程加载运行时代码。`@match` 限定当前 HTTPS 应用，应用在 hash 内切换路由。

第一版无需保存账号或验证码。源码和分发文件都不含真实 Cookie、预约记录 ID、学生信息、HAR 或校园源码全文。
