# 0.4.0 设计

单任务状态机：打开查询 → 显式启动 → 等待提前取图时间 → 获取图片并识别 → 展示可编辑答案 → 开放时提交 → 核验记录。

开放计时与异步取图／识别独立，倒计时期间不轮询学校。默认提前 30 秒；不早于开放时间提交。人工输入使当前 OCR 结果过期；换图清空旧答案，只保留同一轮图片对应的答案。迟到的结果不覆盖新任务。提交与核验锁定输入、换图和关闭。

开放前识别失败保留图片；开放时有人工答案则提交，否则直接换图。开放后的识别失败、明确验证码拒绝或“尚未开放预约”直接换图再试，不查询人数；收到满员、结束、登录或限流提示时停止。“已预约”转入核验。没有长期余位监测。网络写入结果不明先核验，避免重复写入。

验证码图片和答案只保存在当前任务内存中。OCR 资源可缓存；Console 日志只记录选定的安全字段。真实验证码有效期未验证，提前时间是一项可调配置。
