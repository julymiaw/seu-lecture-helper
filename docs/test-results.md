## 浏览器测试内容

使用独立 Chrome 无头会话，不复用用户账号或配置。导航到虚构 `https://lecture.test`，所有 HTTP 请求由测试样例响应；未匹配的业务接口报错，其他源请求被拒绝。未请求学校服务器。

1. 最终构建文件注入实际卡片裁剪 DOM，点击新增按钮、获取图像、聚焦、回车提交、查询核验；原卡片 click 不触发，不调用 appiontCheck。
2. 模拟服务端写入成功后连接中断，脚本只核验，不重复提交。

5. 详情页通过 hash WID 挂载并取图。
