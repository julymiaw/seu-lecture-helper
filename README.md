# SEU 研究生讲座预约助手

提前准备验证码，按本机时间在预约开放后 50 毫秒自动提交；支持同一讲座的线上／线下候选、失败重试和结果核验。

适用于东南大学研究生“人文与科学素养系列讲座”预约系统。浏览器内免费 OCR，无需本地服务、付费识别 API 或密钥。

[Greasy Fork 发布页](https://greasyfork.org/zh-CN/scripts/599922) · [GitHub 源码](https://github.com/julymiaw/seu-lecture-helper) · [问题反馈](https://github.com/julymiaw/seu-lecture-helper/issues)

## 安装与使用

1. 使用 Chrome／Edge 和 Tampermonkey 等用户脚本管理器，通过 [Greasy Fork](https://greasyfork.org/zh-CN/scripts/599922) 或 [GitHub 安装链接](https://raw.githubusercontent.com/julymiaw/seu-lecture-helper/main/dist/seu-lecture-helper.user.js)安装，保留一份启用即可。
2. 在电脑浏览器中打开并登录[研究生讲座预约系统](https://ehall.seu.edu.cn/gsapp/sys/yddjzxxtjappseu/*default/index.do#/hdyy)，在活动列表或详情页点击原按钮旁的“预约助手”。
3. 若找到同一讲座的另一场次，可将其加入候选，选择“线上优先／线下优先”；无法识别场次时，只处理点击的活动。
4. 点击“开始等待”，脚本固定在开放前 **30 秒**取图；活动已开放时点击“立即预约”。
5. 验证码在后台获取并由浏览器内的 OCR 识别，无需查看或输入；按本机开放时间后 50 毫秒自动提交，随后查询预约记录确认结果。

首次使用需下载约 **68 MB** 的识别资源，请提前打开助手准备；资源缓存后，后续复用。

## 自动处理

- **串行候选**：一次只执行一场讲座的预约，最多包含其线上、线下两个场次。优先场次明确满员后，自动换图尝试另一场次；成功即结束，两项都满则停止。
- **统一状态**：一个或两个场次都在同一列表展示进度和结果；停止原因显示在当前场次后，完整失败反馈保留在日志。
- **自动重试**：识别失败、数字不完整、验证码被拒绝或反馈尚未开放时，立即换图识别；不早于设定的开放时间提交。模型初始化持续失败、活动结束或限流时停止，并记录原因。
- **结果核验**：成功后助手按钮显示“已预约”。提交超时或响应不明时先查预约记录；仍无法确认时提供“重新核验”，避免重复提交。
- **会话与恢复**：等待期间定期检查登录状态。登录失效时暂停并保留任务；切换列表／详情不影响等待，同一标签页刷新或登录返回后恢复等待，未确认的提交只恢复核验。
- **面板与日志**：收起面板后任务继续运行，再点助手按钮可展开；关闭任务停止未提交的等待。点击“导出日志”可下载 JSON，包含耗时、验证码持有时长、服务端反馈、重试与候选切换原因。日志在本地保留最近 10 个任务、最长 14 天，刷新后仍可导出；Console 同时提供即时输出。

## 使用提醒

- 保持学校预约标签页在前台、网络连接正常，电脑接电、不合盖、不休眠。首次使用请提前加载识别资源。
- 仅预约本人计划参加的讲座，请勿倒卖名额或代抢牟利；无法参加时及时取消，将名额留给有需要的同学。

## 隐私

验证码在浏览器本地识别，不上传至识别服务；不收集密码或 Cookie，不上传日志。
