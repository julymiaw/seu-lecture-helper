# SEU 研究生讲座预约助手

适用于东南大学研究生“人文与科学素养系列讲座”预约系统。在活动列表和详情页原按钮旁增加“预约助手”，提前获取验证码、在浏览器内识别并预填答案，允许人工修正，到开放时间自动提交并核验结果。

只需要浏览器和用户脚本管理器，无需本地服务、额外软件或 API 密钥。

[Greasy Fork 发布页](https://greasyfork.org/zh-CN/scripts/599922) · [GitHub 源码](https://github.com/julymiaw/seu-lecture-helper) · [问题反馈](https://github.com/julymiaw/seu-lecture-helper/issues)

## 安装与使用

通过 [Greasy Fork](https://greasyfork.org/zh-CN/scripts/599922)或 [GitHub 安装链接](https://raw.githubusercontent.com/julymiaw/seu-lecture-helper/main/dist/seu-lecture-helper.user.js)安装。两个渠道的版本更新可能有时间差，保留一份启用即可。

1. 登录[研究生讲座预约系统](https://ehall.seu.edu.cn/gsapp/sys/yddjzxxtjappseu/*default/index.do#/hdyy)，点击活动旁的“预约助手”。
2. 选择提前取图时间，默认 **30 秒**，可选 10、20、30、60 秒。点击“开始等待”启动；已开放的活动点击“立即预约”。打开弹窗本身不会取图或提交。
3. 到取图时间，弹窗同时显示验证码图片和输入框。模型识别后预填四位数字，你可以直接修改；人工修改不会被迟到的识别结果覆盖。需要更新图片时点击“换一张”。
4. 开放时自动提交输入框里的最终答案。无需选择自动／手动模式，也无需再点提交。若到点识别仍未完成，识别完成后立即提交；答案为空时不会发送空验证码。
5. 已开放后，可通过“提交预约”或回车提交人工填写的答案。提交后自动查询预约记录，确认成功后助手按钮显示“已预约”。

弹窗收起后任务继续运行，再点击活动旁的助手按钮可恢复。关闭任务会取消未提交的倒计时；提交和核验期间暂时不能关闭。

## 验证码与重试

首次打开助手需要下载约 **68 MB** 的模型、字符表和 WASM 引擎，请提前打开准备。资源校验后缓存在学校站点的浏览器存储中，后续复用；清理网站数据后可能需要重新下载。图片在本地识别，不上传至识别服务。

开放前识别失败时保留图片供人工填写，若到点仍没有有效答案则自动换图重试。开放后识别失败或服务端明确提示验证码错误时，立即换图识别并再次提交，不额外查询人数，不设固定重试次数或额外等待。收到“尚未开放预约”也换新验证码再试，不主动提前提交。收到满员、结束、登录异常或限流提示便停止。模型资源不可用时保留输入框供人工填写，不循环下载。

提交超时或返回无法解析时，先核验预约记录，不盲目重发。仍无法确认则显示“结果待确认”，提供“重新核验”。不提供长期余位监测，也不会取消已有预约。

**提前取图的实际有效期尚未完成当前系统的实网验证。**若提前验证码失效，依靠明确的验证码错误响应换图重试；取到验证码不代表占位，也不保证预约成功。

## 失败诊断

预约前打开浏览器开发者工具的 Console，开启“保留日志”，筛选 `[SEU预约助手]`。日志记录取图、OCR、提交和核验耗时，以及取图距开放时间的偏差、重试原因和最终状态，同一任务使用统一编号。

不输出登录凭据、验证码图片或答案，不上传日志。页面关闭后不保证能恢复日志。问题反馈请注明版本、浏览器、操作步骤，并提供对应任务的日志。

## 使用须知

- 使用新版 Chrome／Edge 和 Tampermonkey 等用户脚本管理器；其他浏览器尚未验证。仅适配上述研究生入口。
- 保持页面打开、登录有效。后台标签页节流、电脑休眠和网络拥堵可能延迟执行；刷新或关闭页面会结束任务。
- 同一浏览器、同一站点只运行一个助手任务。已预约、已取消、满员或预约结束的活动不会启动预约。
- 学校原按钮可能仍显示旧状态，成功后可点击“刷新学校页面”更新。
- 脚本不保存密码、Cookie 或验证码；仅缓存公开识别资源。资源下载请求不携带学校 Cookie 或验证码。

这是非官方辅助工具，请遵守学校预约和参与活动的要求。
